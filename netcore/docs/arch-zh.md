# NetCore 架构设计

## 概述

NetCore 是基于 libuv 构建的异步网络库，为多种传输协议提供统一 API，支持零拷贝缓冲区。

```
┌─────────────────────────────────────────────────────────────┐
│                        应用层                                │
├─────────────────────────────────────────────────────────────┤
│     async_client_t          │        async_server_t          │
│  ┌─────────────────────┐    │    ┌─────────────────────┐    │
│  │     事件回调         │    │    │     事件回调         │    │
│  │  (connected/data/   │    │    │  (listen/conn/data/ │    │
│  │   closed/error)     │    │    │   disconnect/error) │    │
│  └─────────────────────┘    │    └─────────────────────┘    │
├─────────────────────────────┼───────────────────────────────┤
│              传输层 Vtable（多态）                            │
│  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐ ┌──────┐ ┌───────────┐    │
│  │ TCP │ │ UDP │ │ KCP │ │ TLS │ │ PIPE │ │ WebSocket │    │
│  └──┬──┘ └──┬──┘ └──┬──┘ └──┬──┘ └──┬───┘ └─────┬─────┘    │
│     └───────┴───────┴───────┴───────┴───────────┘           │
├─────────────────────────────────────────────────────────────┤
│                        libuv                                 │
│  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────────────┐    │
│  │ uv_tcp  │ │ uv_udp  │ │ uv_pipe │ │ uv_async/timer  │    │
│  └─────────┘ └─────────┘ └─────────┘ └─────────────────┘    │
├─────────────────────────────────────────────────────────────┤
│                       操作系统                               │
│            (epoll / kqueue / IOCP / select)                  │
└─────────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. 传输层 Vtable

每种传输通过 vtable 实现统一接口，实现多态行为：

```c
typedef struct {
    int (*setup)(void *transport, void *loop);
    void (*close)(void *transport);
    int (*connect)(void *transport, const char *host, int port);
    int (*send)(void *transport, const char *data, size_t len);
    int (*sendv)(void *transport, const async_client_iovec_t *iov, size_t iovcnt);
    int (*get_state)(void *transport);
} async_client_transport_ops_t;
```

**优势：**
- 添加新传输无需修改核心代码
- 运行时选择传输协议
- 所有协议使用一致的 API

### 2. 事件驱动架构

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   libuv      │────>│    事件      │────>│    用户      │
│   事件       │     │    分发      │     │    回调      │
└──────────────┘     └──────────────┘     └──────────────┘
       │                    │
       │              ┌─────┴─────┐
       │              │           │
       v              v           v
   ┌──────┐      ┌──────┐    ┌──────┐
   │ 读取 │      │ 写入 │    │ 定时 │
   └──────┘      └──────┘    └──────┘
```

事件通过单一回调传递：

```c
typedef void (*async_client_event_cb)(
    async_client_t *client,
    const async_client_event_t *event,
    void *user_data
);
```

### 3. 零拷贝缓冲区系统

```
┌─────────────────────────────────────────────────────────────┐
│                      turbo_arena_t                           │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                      内存池                          │    │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   │    │
│  │  │ Buffer1 │ │ Buffer2 │ │ Buffer3 │ │   ...   │   │    │
│  │  │ 引用=2  │ │ 引用=1  │ │ 引用=0  │ │         │   │    │
│  │  └────┬────┘ └────┬────┘ └─────────┘ └─────────┘   │    │
│  └───────┼──────────┼──────────────────────────────────┘    │
│          │          │                                        │
│          v          v                                        │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                     切片 (Slices)                    │    │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐               │    │
│  │  │ Slice A │ │ Slice B │ │ Slice C │               │    │
│  │  │ buf=1   │ │ buf=1   │ │ buf=2   │               │    │
│  │  │ off=0   │ │ off=100 │ │ off=0   │               │    │
│  │  │ len=100 │ │ len=50  │ │ len=200 │               │    │
│  │  └─────────┘ └─────────┘ └─────────┘               │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**核心概念：**

- **Arena**: 用于分配缓冲区的内存池
- **Buffer**: 引用计数的内存块
- **Slice**: 缓冲区的零拷贝视图（偏移量 + 长度）

**生命周期：**

1. 从 arena 分配缓冲区
2. 创建指向缓冲区的切片
3. 将切片传递给发送函数（引用计数增加）
4. 释放你的引用（引用计数减少）
5. 库在发送完成后释放（引用计数 = 0，缓冲区回收）

## 线程模型

NetCore 为每个客户端/服务端使用单线程事件循环：

```
┌─────────────────────────────────────────────────────────────┐
│                        主线程                                │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                  应用代码                            │    │
│  │                                                      │    │
│  │  client = async_client_create(...)                   │    │
│  │  async_client_connect(client, ...)                   │    │
│  │                                                      │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                           │
                           v
┌─────────────────────────────────────────────────────────────┐
│                    内部 I/O 线程                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              uv_loop_t                               │    │
│  │                                                      │    │
│  │  while (running) {                                   │    │
│  │      uv_run(loop, UV_RUN_DEFAULT);                   │    │
│  │  }                                                   │    │
│  │                                                      │    │
│  │  事件在此线程分发给用户回调                           │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**线程安全：**
- API 调用是线程安全的（使用内部异步队列）
- 回调在 I/O 线程执行
- 回调中访问用户数据无需同步

## 内存管理

### 缓冲区生命周期

```
1. 分配
   turbo_arena_get_buffer(&arena, size)
   └── 返回引用计数 = 1 的缓冲区

2. 创建切片
   turbo_arena_buffer_to_slice(buf, len)
   └── 切片引用缓冲区，引用计数仍为 1

3. 发送
   async_client_sendv_slices(client, &slice, 1)
   └── 库增加引用计数到 2

4. 用户释放
   turbo_arena_slice_release(&slice)
   └── 引用计数减少到 1

5. 发送完成
   └── 库释放，引用计数 = 0
   └── 缓冲区回收到 arena
```

### Arena 增长

```
初始:  [████████████████] 64KB

分配 48KB:
       [████████████░░░░] 已用 48KB

分配 32KB（超出容量）:
       [████████████████████████████████] 128KB（自动增长）
       [████████████████░░░░░░░░░░░░░░░░] 已用 80KB
```
